# 鹊信定时维护进程验收

更新日期：2026-10-29

## 职责

- 删除 `expires_at` 已到期的数据导出任务及 `.json.gz` 文件。
- 删除已标记删除或 pending 超过 24 小时的媒体行及文件。
- 执行未撤销且 `scheduled_at` 已到期的空间删除，并清理其媒体和导出文件。
- 清除过期会话、7 天前撤销的会话、过期令牌和 7 天前已使用令牌。
- 将成功、部分完成或失败结果写入 `maintenance_runs`。
- 物理文件部分失败写入 warning 告警；维护事务失败写入 critical 告警。

## 权限

- 普通正式 API 使用受 RLS 限制的应用角色。
- 维护进程必须使用独立 `MAINTENANCE_DATABASE_URL`。
- `maintenance_runs` 允许登录用户读取，但应用角色没有写入策略。
- `system_alerts` 同样只允许登录用户读取，写入由维护角色完成。

## 可控时间测试

`npm run test:maintenance` 创建两个临时空间和隔离临时文件目录：

- 到期空间：被删除，关联媒体与未来导出文件同时移除。
- 保留空间：继续存在。
- 过期导出：数据库行和文件均移除。
- 25 小时 pending 媒体：行和文件均移除。
- 有效媒体、有效会话：保持存在。
- 过期会话、过期令牌：移除。
- 维护记录：状态为 `success`，计数全部符合预期。

测试完成后会在 `finally` 中删除临时用户、维护记录和临时目录。
