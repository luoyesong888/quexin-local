# P12 青鸟普通对话与产品工具验收

日期：2026-11-02。

## 已实现

- 统一 `/v1/assistant/chat` 新增 `conversation` 操作和严格结构化回复。
- “你现在可以做什么”由本机真实能力清单即时回答，不消耗模型请求。
- 普通问候和一般讨论可调用模型，并携带最近 10 条纯文本用户/青鸟消息。
- 普通对话不携带回忆、计划、附件二进制、工具内部字段、日志或 API Key。
- 个人事实问题继续使用来源检索；没有来源时明确不知道，不交给通用模型猜测。
- 青鸟可调用白名单产品工具：页面导航、小鹊互动、主题/模块、备份和纪念馆导出。
- 删除账号/空间、恢复备份、密码和 API Key 不提供直接工具，只能打开原确认页面。

## 验收

- 空白账号能力询问、普通聊天、两轮上下文通过。
- 普通对话请求不含示例回忆正文；个人事实问题没有新增模型请求。
- “打开计划、切换主题、喂小鹊、导出备份”产生工具草稿并在确认后真实执行。
- 产品工具目录与服务端白名单一致，伪造页面、主题或工具 ID 被拒绝。
- AI/Agent 26 条流程、完整回归 42/42、WorkBuddy 最终压缩包全新安装通过。
