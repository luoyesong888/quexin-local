## 已实现

- “系统 → 空间与功能 → 共享与账号管理”展示本人已同步资料和照片的服务端状态，可撤回记录或照片。
- 撤回记录后，服务端保留作者的私人版本；另一成员收到不含正文的删除事件，不能继续读取。旧设备不能用普通更新重新公开，作者必须走明确重新共享操作。
- 撤回记录会将本人关联照片改为仅自己。单独撤回照片会同时撤回本人关联记录，避免文字继续引用另一成员已不可读的媒体。
- 另一成员不能撤回作者资料或照片。未共享过的资料重复撤回不会广播其标识；删除实体和冲突响应不再携带旧正文。
- 每次共享范围、实体或媒体变化都会推进隐私版本，使此前生成的服务端数据包链接失效；生成期间发生变化也会拒绝完成旧快照。
- 退出共同空间需输入完整确认文字。本人服务端贡献与照片撤回，本机资料转为私人归档；加入新空间时旧归档不会自动重发。还有另一位成员时，对方成为创建者并保留自己的资料和小鹊；只剩自己时服务端空间删除。
- 注销账号需当前密码和“注销我的账号”。所有会话、令牌、本人服务端贡献、账号浏览器资料、同步队列和宠物队列被清理；另一成员及其资料保留。邮箱可在注销完成后重新注册为新账号。
- 数据库跨表生命周期操作使用受控函数并在单一事务中完成。普通应用角色不能读取文件清理队列。
- 媒体和数据包物理文件采用持久清理任务。权限先撤销；磁盘删除失败时记录重试，维护进程或 `npm run local:cleanup` 再处理，不把失败静默丢掉。
- 撤回应答丢失时界面保留错误，不猜测操作状态；刷新共享状态后以服务端结果为准。

## 数据规则

- 撤回限制鹊信服务端之后的新读取；不会删除对方此前已经下载、截图、另存或自行备份的副本。
- 退出空间默认保留本机私人归档。注销账号会清除当前浏览器该账号的资料，但用户自行导出的 JSON 和其他设备的离线副本仍需用户自己删除。
- 创建者退出时，空间交给留下成员；创建者不能借退出删除另一成员自己的记录。共同宠物保留数值状态，成员事件和成长手记重置为中性说明，避免离开成员的名称继续暴露。
- P2 迁移使此前所有服务端数据包链接失效，需要重新生成。已经下载到磁盘的包不受影响。
- 文件清理队列保证可重试，不保证在权限撤销同一毫秒完成物理删除；应用层读取会先被拒绝。
