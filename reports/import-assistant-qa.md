# 本地收尾阶段三：导入与青鸟助手

日期：2026-10-30

## 已实现

- 导入支持粘贴、TXT、JSON 消息列表或 messages/records 容器；非法 JSON、未知对象、过量消息明确报错，不替换现有内容。人物映射针对原说话人一次替换，避免别名碰撞导致再次替换。
- 每条候选保存批次、来源类型/名称、整理文本行号、映射前后文本、基准日期和整理时间。TXT 空行不会打乱来源行号；JSON 行号对应转换后的整理文本。
- 候选、回忆详情和青鸟引用共用来源组件。后续编辑回忆正文保留导入依据；来源信息随浏览器保存、备份和共享记录保留。
- 模糊或互相矛盾的日期进入待核对状态，不直接猜作今天。回忆/计划需补充具体日期；心愿/偏好允许暂缺日期。日期核对不再自动等同于私人内容。
- 私人候选需单独确认，不自动派生共享日程。新确认的公开计划保留来源记录编号；问答与同步筛选也排除来源为私人记录的旧派生日程。
- 青鸟检索只引用已确认、非私密记录；待确认、忽略、私人记录与私人照片记录不进入检索。删除或更改当前记录时重新计算回答，避免继续展示旧引用。
- “第一次”查询表述为已确认资料中最早的一条，不把检索结果断言为现实中的第一次。相伴天数说明来自空间日期设置；日程回答来自可引用的待完成安排。
- 手机从底部记录入口导入后，可打开顶部青鸟助手提问并查看来源详情。
- 设置页新增能力状态，准确说明本地规则、本地检索、人工图片文字及尚未连接的外部能力。

## 能力边界与后续

- 本阶段验收的是本地规则与检索版本。未接入真实大模型、OCR 或微信账号；模型服务商、鉴权、调用失败处理与质量评估仍需在明确服务和资料范围后实现并独立验收。
- 来源依据为导入页面中用户核对的文本。图片文字由用户输入，JSON 会转换为消息行；并非原始文件字节级存证或 OCR 识别证据。
- 隐私筛选覆盖当前资料的问答和新同步候选；历史已提交或已进入旧同步队列的数据撤回不包含在本阶段验收中，不能据此承诺远端资料已删除。
- 手机证据来自浏览器视口模拟，未代表真实 iPhone/安卓或系统后台行为。整站主题、交互和视觉验收继续在第四阶段完成。
- PWA 本阶段仅重新构建；没有将构建成功称作新增后台调度验收。
