# 完整产品 P7：跨端体验、无障碍与性能

日期：2026-10-31。P7 的自动化范围已通过；实体 iPhone/安卓、系统 Safari/Chrome 和 VoiceOver/TalkBack 仍需按真机清单人工验收，因此本报告不把模拟结果表述为“真机全部通过”。

## 已实现

- 增加“跳到主要内容”链接，主要内容区可编程聚焦；单页路由切换后焦点进入新页面主区域，读屏用户不必重新穿过全部导航。
- 原生 `dialog` 补充 `aria-modal` 和标题关联；验证初始焦点、Tab 焦点约束、Esc 关闭及焦点返回触发按钮。
- 动态提示使用礼貌、原子化状态播报，不抢走当前输入焦点。
- 修复默认主题及其余九种主题的文字/强调色对比度，包括浅色辅助文字、导航编号、特殊印章和主题特有活动状态；未关闭 axe 对比度规则。
- 调整日历日期的可访问名称，使可见日号包含在语音控制名称内。
- 增加 Chromium、Firefox、WebKit 桌面环境，以及 Pixel Chromium、iPhone WebKit 移动模拟环境。
- 覆盖八页面导航、创建与刷新持久化、备份下载、横竖屏、模拟软键盘、最小 24×24 CSS px 触控目标、200% 等效视口和 320px 回流。
- 增加大数据备份门禁：1,000 条回忆、500 条计划、300 篇文字，覆盖恢复、IndexedDB 持久化、刷新、搜索、切页、新增保存和再导出。

## 本机性能结果

测试备份为 1,005,345 字节。单次本机 Chromium 结果：

| 操作 | 耗时 |
| --- | ---: |
| 备份解析与预览 | 75 ms |
| 恢复渲染 | 103 ms |
| IndexedDB 持久化等待 | 14 ms |
| 刷新并重新读取 | 209 ms |
| 打开 1,000 条回忆页 | 423 ms |
| 精确搜索 | 58 ms |
| 打开 500 条计划页 | 142 ms |
| 打开 300 篇创作页 | 85 ms |
| 在大数据集后新增并保存 | 1,314 ms |
| 再导出完整备份 | 40 ms |
| 工作流最长主线程任务 | 245 ms |

机器、浏览器版本和数据内容会影响耗时；这些数字是回归基线，不是所有设备的性能承诺。原始值见 [性能指标](product-p7-qa/performance-metrics.json)。
