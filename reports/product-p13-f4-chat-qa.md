# P13 F4 青鸟聊天接入验收

日期：2026-11-03。全部使用临时目录内的合成聊天、图片和模拟模型，不处理真实聊天、不启用真实交换箱。

## 完成范围

- 同一青鸟输入框路由 WorkBuddy 检查、聊天检索和片段整理，自动发现已绑定目录的新批次。
- 正式登录会话取得账号、服务端取得当前空间，客户端身份字段仅用于防止切号竞态；所有接口限本机访问，保持同源保护。
- 首次绑定需账号密码及明确目录授权，读取卡显示联系人、日期、条数/图片数与私有范围。
- 原子批准与归档，避免监视器抢占 UI 任务；实际归档数量进度、取消、失败提示、修复后重新确认。
- 关键词、日期、发送者检索和分页，按需读取单条完整原文。
- 每次最多 6 条（同时受模型来源上限限制）、每条最多 1,000 字；服务端保存精确预览，发送确认绑定登录会话/空间/模型配置，5 分钟内单次使用。
- 本地保守整理或模型整理，候选不自动写入；逐条编辑、核对日期、保存为私人记录。每条包含批次、消息、分块、行号与清单摘要，可从记录来源返回本机原文。
- 未确认原文、查询、预览和候选不持久化到浏览器、普通聊天历史或同步队列；明确保存的候选和引用节选进入当前账号浏览器资料库。

## 使用与边界

- 对青鸟输入“检查 WorkBuddy 新聊天”“搜索聊天记录：海边”“整理这些聊天片段”。首次连接和资料范围在对话中确认。
- WorkBuddy 仍由用户发起提取，按固定目录/协议写文件；鹊信不会遥控 WorkBuddy 或直接读取微信。
- 模型结果仍需人工核对，默认私人保存；计划类候选是记录，不自动安排日程、发送消息或分享给伴侣。
- 无双人空间使用 `personal`；加入/退出空间后须使用对应空间的独立绑定，不把旧空间归档自动迁移给新空间。
- 原始归档不在普通浏览器/服务端备份内；用户需保留原始导出。明确保存的私人记录及节选会进入用户主动导出的浏览器 JSON 备份。
