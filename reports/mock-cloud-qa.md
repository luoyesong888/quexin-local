# 鹊信本地模拟云验收

更新日期：2026-10-28

## 自动契约测试

运行 `npm run test:mock-cloud`，使用临时端口和临时数据目录，以下项目全部通过：

- 三个独立模拟账号登录。
- 甲创建情侣空间并生成限时邀请码。
- 乙接受邀请，空间成员达到两人。
- 第三人读取和写入均返回 `FORBIDDEN`。
- 相同 `commandId` 重试不会重复增加实体版本。
- 乙通过增量变化接口取得甲提交的共享回忆。
- 乙更新回忆后版本从 1 增加到 2。
- 甲使用过期版本更新时收到版本冲突和服务端当前版本。
- 甲的私人记录不会返回给乙。
- 测试结束后临时服务和临时数据自动清理。

## 可见界面验收

在设置页“空间与功能 → 双人同步实验室”完成：

1. 体验甲登录本地模拟账号。
2. 创建情侣空间并生成 24 小时邀请码。
3. 独立标签页中的体验乙登录并输入邀请码。
4. 两个标签页均显示空间已有 2/2 人。
5. 甲提交 10 项可共享资料。
6. 乙拉取云端变化成功。
7. 两边退出模拟会话。

UI 验收产生的模拟服务数据已移到 `.backups/mock-cloud-qa/20261028-contract-ui.json`，当前 `.local-data/mock-cloud.json` 会从空环境重新创建。

## 边界

该服务只用于本机契约验证，不具备生产认证、加密密钥管理、PostgreSQL、对象存储、邮件/短信、限流或公网安全配置。不得直接部署到公网。
