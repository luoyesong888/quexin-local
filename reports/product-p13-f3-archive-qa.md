日期：2026-11-03。使用临时目录里的合成聊天与图片，未处理真实聊天。

## 交付

- 独立的本机 SQLite 归档，账号/空间分开，目录 0700、数据库 0600。
- 后台 Worker 写入、检索、超时与取消处理。
- 清单绑定的显式归档授权；原有 F2 仅校验授权不会自动扩展。
- 消息和批次幂等、增量水位、冲突整批回滚、提交收据与崩溃恢复。
- 来源 ID 优先、与序号无关的回退消息 ID、F1 旧批次兼容。
- 中文关键词/日期/发送者筛选，固定快照分页，相关片段上限和原文引用。
- `workbuddy-chat` 来源引用契约；正文未进入现有浏览器记忆与同步结构。
- CLI 查询及后台批准批次消费，导航和青鸟 UI 待 F4/F5。

本机 Node 22.22.3；10,000 条合成消息、264 张 8×8 合成 PNG：批准后归档 6,588 ms，含 Worker 启动的中文关键词查询 127 ms，归档期间主线程 10 ms 心跳执行 609 次。此数据不代表真实大图、其他电脑或更大数据量的保证。只测量后台线程响应，没有声称完成真实浏览器卡顿测量。

## 隐私与边界

- 原文只写入本机专用数据库，不自动生成正式回忆或共享数据，不调用模型。
- 查询片段和原文是显式查询结果；状态、运行日志和收据不含正文。
- 图片字节保留在交换箱，数据库仅保存相对引用和哈希；源图片删除后引用可能不可用。
- 无原始 ID 时，跨批次完全同刻同文重复存在不可消除的歧义，记录回退身份数量并保留每次来源位置供核对。
- 取消回滚未提交事务并暂停归档；已完成提交不由迟到的取消撤销。进程异常退出会在下次同步中恢复。
- 本地文件权限不等于加密。普通浏览器/服务端备份当前不包含归档；用户需另外保留原始导出。
- SQLite 使用 Node 内置接口，在当前 Node 22 下仍为实验性能力；Worker 显式带兼容标志。依据 [Node 官方 SQLite 文档](https://nodejs.org/download/release/v22.23.0/docs/api/sqlite.html)。
- F4 网页访问必须由服务端认证账号限定读取，不得将可信本机 CLI 的显式账号参数直接当作网页授权。
