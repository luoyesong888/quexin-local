# 完整产品 P5：日程、提醒与关怀分享

日期：2026-10-31。P5 的本地计划、浏览器内提醒和双账号关怀分享已通过自动化验收；实体手机在浏览器完全关闭后的系统后台定时仍待 P7 真机验收。

## 已实现

- 计划支持不重复、每天、每周、每月、每年，以及可选结束日期。日历按实例显示，编辑仍修改原计划。
- 重复计划每个发生日独立完成；完成一次不会关闭整个系列，下一实例继续显示和提醒。每个已完成实例可分别存成回忆。
- 每条计划保存 IANA 时区、提醒提前量（准时、10/30/60 分钟、1 天）和已完成实例。
- 时区换算覆盖月底不存在日期、闰日和夏令时不存在时间；无法对应的本地时间不产生错误提醒。
- 提醒在应用打开、计划更新和页面恢复可见时检查。页内提醒无需通知权限；允许权限时向 Service Worker 请求浏览器通知。
- 通知记录使用独立 IndexedDB 和 Web Lock，跨刷新/标签页按计划、实例、时间、提前量去重。完成或取消的实例不提醒。
- 界面明确说明：系统完全关闭浏览器后不保证准时触发，不把页面恢复检查称作手机后台调度。
- 关怀分享使用服务端 `care_signals`，每位成员一条当前信号，允许四种需要、可选 280 字短消息和 1—72 小时有效期。
- 用户明确点击后才发布；对方看到发送者、需要、短消息和到期时间。作者可更新或撤回，过期后服务端不再返回。
- 私人草稿和周期信息不进入关怀请求。未登录或未加入共同空间时，仅本机保存，不显示发送按钮。
- 创建者退出、成员离开或账号注销时，对应关怀信号一并删除。PostgreSQL 使用 RLS 限制成员读取和作者写入。

## 重要边界

- 自动化在生产 PWA 中模拟“通知权限允许”和 `showNotification` 适配器，验证应用发出一次通知请求并去重；没有把无头浏览器测试称为操作系统通知中心实际展示。
- 浏览器或手机系统可能限制后台运行、定时器、通知权限和省电策略。浏览器完全关闭后的精确定时需要实体 iPhone/安卓及目标浏览器验收。
- 关怀分享不是聊天或紧急求助功能，不推测情绪、健康或风险；过期/撤回只阻止鹊信后续读取，不能删除对方已截图的内容。
- 当前提醒数据保存在本机浏览器；计划本身可按既有共享规则同步，通知权限和“已通知”状态不在设备间同步。
