# 鹊信 macOS 本地包最终能力

## 零外部密钥即可使用

- 本地账号、验证/重置预览、双账号空间和邀请；
- 回忆、照片、搜索、来源、撤回和浏览器备份；
- 计划、重复规则、时区、页内提醒和关怀；
- 鹊巢成长、互动、房间和成长来源；
- 信件、日常、年度回顾、离线纪念馆；
- 服务端加密时光胶囊；
- TXT/JSON/CSV/HTML 和图片人工文字导入；
- 青鸟本地资料检索；
- 五组件运行、维护、通知 outbox、doctor、服务端备份恢复；
- WorkBuddy 安装、配置、升级、回滚和安全卸载。

## 使用者提供自己的配置后可启用

- 设置页安全录入 DeepSeek 或 OpenAI 兼容 API，密码二次确认、密钥不回传、600 权限保存和自动重启；
- DeepSeek / OpenAI 兼容模型问答、候选整理、辅助写作和图片 OCR；
- 青鸟个人 Agent 十个 Skill：零资料直接指令、个人记忆/计划/创作、新导入发现、图片连续工作流、计划跟进、日历/邮件草稿和多轮关系回顾；
- 青鸟统一聊天界面：无功能分页和模式按钮，文字、图片、文件、资料确认、审批、工具结果和引用在同一消息流；
- 普通自然对话与最近有限轮次上下文；个人事实继续来源化，避免无资料时由通用模型猜测；
- 十个产品工具：主页面导航、小鹊互动、个人主题/模块切换、浏览器备份与离线纪念馆导出；高风险操作只导航到原确认流程；
- Agent 运行持久化、Skill 白名单、逐项审批、ICS 下载和本机邮件客户端草稿；
- 微信聊天提取保持能力门禁关闭，只有 WorkBuddy 真实适配器通过验收后才可加入白名单；
- OpenAI 兼容服务提供的录音转写模型（DeepSeek 模式保持关闭）；
- SMTP 实际邮件投递。

配置不是发布包必需条件，错误配置会回滚到旧配置。

## 明确不包含

- 公网托管、域名、HTTPS、对象存储和多实例；
- 手机真机、原生 App 和系统级后台推送；
- 个人微信直连；
- 两台独立电脑之间无需共同主机的自动同步；
- 端到端加密、第三方可信时间或远程删除对方已保存副本。
