# P11 青鸟统一聊天式个人智能体验收

日期：2026-11-02。

## 改造结果

- 青鸟不再显示“为你整理 / Agent / 来源 / 记录”分页。
- 不再显示“直接指令 / 图片工作流 / 多轮回顾 / 使用已有资料”等模式按钮。
- 页面只保留顶部身份与运行详情、中间连续消息流、底部附件与唯一输入框。
- 问答、直接指令、新导入发现、计划跟进、资料回顾和附件由本地意图路由自动选择。
- 资料范围、动作审批、修改、拒绝、真实工具结果和引用均作为聊天消息显示。

## 数据与兼容

- 新增持久化 `assistantMessages`，保存用户消息、资料范围、Agent run 引用、工具结果和错误恢复。
- 旧 `agentRuns` 在首次进入统一聊天时迁移为历史运行消息。
- 旧 `/assistant/answer` 与 `/assistant/agent` 保留；新客户端使用统一 `/v1/assistant/chat`。
- 浏览器 JSON 备份包含会话、审批和结果；旧备份缺失会话时按空主线程加载。

## 安全边界

- 模型读取资料前显示范围卡，可调整、取消或仅使用本地检索。
- 每个本机写入和外部动作独立审批；编辑后的字段再确认。
- 停止请求会中止上游并回退本地，不生成伪造结果。
- 微信聊天提取门禁保持关闭，主附件菜单不显示微信入口。

## 自动验收

- 统一聊天无分页/无模式按钮、唯一输入框、问答和 Agent 自动路由通过。
- 图片 OCR→回忆→计划→ICS、资料范围调整、草稿编辑、审批/拒绝、取消与备份恢复通过。
- 手机 390、桌面 1440 无裁切；WCAG 与键盘扫描通过。
- AI/Agent 24 条流程、完整回归 42/42、WorkBuddy 最终压缩包全新安装通过。
