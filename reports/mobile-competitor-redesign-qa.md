# 鹊信手机交互改版验收

日期：2026-10-27  
尺寸：390×844，另对十种主题进行横向溢出检查  
环境：本地 Vite Demo，Chrome

## 改版结果

手机首页从“功能总览”改成四段内容：今日行动、轻量鹊巢、下一项日程、最近回忆。底栏固定为“今天、回忆、记录、日程、鹊巢”，其中“记录”打开统一动作面板。搜索移动到回忆页，设置通过顶部双人头像进入，顶部只保留青鸟与头像两项操作。

## 实际操作验收

| 项目 | 结果 |
| --- | --- |
| 390×844 首页 | 今日行动为第一焦点，首屏同时露出鹊巢；无横向溢出 |
| 底栏 | 五项宽度均约 73px；中央记录按钮上浮但未超出安全区 |
| 今日行动 | 显示第一条待确认候选、来源摘要、原文与确认两个清晰动作 |
| 记录动作面板 | 底部面板显示回忆、聊天/照片、计划、信件、需要五个入口 |
| 写一段回忆 | 直接打开回忆编辑器，不再先进入模块首页 |
| 添加一件计划 | 直接打开计划表单，预填当天日期 |
| 浏览器返回 | 从计划表单关闭并返回后回到今日首页 |
| 鹊巢预览 | 首页只展示房间、宠物、羽光/安心和两个动作；完整管理留在鹊巢页 |
| 十种主题 | paper、ink、vivid、bamboo、cosmos、jade、sunlight、heritage、film、brocade 全部切换成功，body 无横向溢出 |
| 构建 | `npm run build` 通过；PWA 生成 13 个预缓存资源 |

## 保留的完整流程

- 导入聊天、图片与文件，生成人工确认候选。
- 回忆搜索、编辑、删除和来源查看。
- 日历与计划状态流转。
- 鹊巢完整互动、房间布置与成长日志。
- 关怀、私人草稿、信件、胶囊、年度回顾和离线导出。
- 十种主题、本地备份恢复和离线 PWA。

## 边界

本轮是本地 Demo 的手机交互改造，没有真实用户漏斗数据。今日行动的优先级目前是“待确认候选 → 最近计划 → 新建回忆”；正式产品应根据内测行为数据再决定长期排序。
