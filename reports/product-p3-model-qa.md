# 完整产品 P3：真实青鸟助手

日期：2026-10-30。P3 的代码与隔离测试提供商验收已完成；当前本机没有 `ASSISTANT_API_KEY` / `OPENAI_API_KEY` 和 `ASSISTANT_MODEL`，所以**真实外部模型尚未实际调用，P3 不能标记为最终通过**。

## 已实现

- 服务端 Responses API 代理，浏览器只看到启用状态、服务商、模型名、超时和资料上限；API 密钥与服务地址不会下发浏览器或进入备份。
- 配置状态与模型调用均要求登录会话，配置接口未登录返回 401。请求按账号限流。
- 问答先执行本地检索，只选择已确认、非私密记录和待完成日程。真实模型模式下先展示标题、日期、类型和正文摘要；用户每次可以确认发送或改用本地检索。
- 导入页显示本次将发送的行数、人物称呼和基准日期；原始图片不发送。用户可取消模型候选整理。
- 服务端再次拒绝敏感、待确认、超量和非法结构；来源正文按配置截断。客户端即使伪造 `sensitive:false` 以外的私人输入，也不会进入提供商。
- Responses API 使用严格 JSON Schema。问答只接受 `answer / citationIds / uncertainty`；候选只接受受限类型、日期和真实原文行号。
- 引用 ID 必须属于本次发送范围；虚假引用、无效 JSON、结构错误、拒绝、HTTP 错误、超时和断流不会采用模型答案，问答回退本地检索，候选回退本地规则。
- 上游使用 SSE。浏览器取消后，AbortController 传到服务端和上游；重复提问会取消旧请求。
- 日志只记录调用状态与引用数量，不记录密钥或完整发送正文。当前模型结果不自动保存成正式记录，候选仍需逐条确认。
- `.env.local` 提供本机私密配置方式，已由 gitignore 排除；占位符不会误启用模型。

## 配置方式

复制 `.env.example` 为 `.env.local`，填写：

```text
ASSISTANT_API_URL=https://api.openai.com/v1
ASSISTANT_API_KEY=服务端密钥
ASSISTANT_MODEL=账号实际可用且支持 Structured Outputs 的模型名
```

然后重启 `npm run local:stop && npm run local:start`。不在浏览器设置页填写密钥，避免进入前端存储和导出包。
