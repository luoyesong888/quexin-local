# P10 青鸟个人智能体实施计划

## 目标

让青鸟在零回忆、零计划、未上传文件时也能工作。用户直接输入自然语言指令，Agent 将用户本次指令视为明确授权的第一方来源，选择个人管理 Skill，生成逐项可审批的本地动作。

## 阶段

1. [完成] 扩展 Skill 目录：新增指令收件箱、个人记忆、个人计划/习惯、个人创作四个 Skill。
2. [完成] 扩展 Agent 协议：支持零资料运行、周期计划、私人关怀和信件/日记草稿。
3. [完成] 直接指令工作台：默认进入指令模式，提供可输入和可点击示例，不要求选择既有来源。
4. [完成] 动作执行：偏好/回忆、提醒/周期习惯、私人关怀、信件/日记仍逐项审批。
5. [完成] 微信能力门禁：只有 WorkBuddy 存在经过验收的聊天提取适配器时才注册微信 Skill；当前保持不可用。
6. [完成] 测试、完整回归与 WorkBuddy 发布包。

## 直接指令示例

- “记住小满不吃香菜。” → 偏好草稿。
- “下周五提醒我准备纪念日礼物。” → 提醒草稿。
- “每周六安排一起散步。” → 周期计划草稿。
- “今天有点累，先帮我记成私人关怀草稿。” → 私人关怀草稿。
- “根据刚才这句话帮我写一封信。” → 信件草稿。

## 不变量

- 用户指令可以作为来源，但不得把模型猜测写成事实。
- 所有持久化动作继续先生成审批卡；拒绝不产生副作用。
- 零资料允许运行，但资料型回顾仍必须有被选择的资料。
- 微信不是默认能力。必须同时具备适配器、权限说明、样本验收、来源行号和失败回退，才可把 `wechat-chat-import` 加入运行时白名单。
- 不允许通过截图模拟或“微信演示开关”冒充已经接入真实聊天提取。

## 验收

- 空白账号可直接输入指令并生成偏好、提醒、周期计划、关怀或创作草稿。
- Agent 根据目标组合 `command-inbox` 与必要的个人 Skill。
- 旧六个 Skill 和历史 Agent run 兼容。
- 微信 Skill 在当前能力状态下不可选，服务端拒绝伪造调用。
