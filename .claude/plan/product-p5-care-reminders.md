# P5 日程与关怀实施计划

## 目标

计划支持重复、时区与本机提醒；关怀需要只在用户明确发布后让另一账号看到，可撤回并自动过期。页面打开时和恢复可见时检查到期提醒；不承诺浏览器被系统完全关闭后的精确定时。

## 子任务

1. [完成] 计划模型：时区、重复规则（日/周/月/年）、提醒提前量和结束日期，兼容旧计划与同步。
2. [完成] 时间计算：以 IANA 时区计算提醒时刻与重复实例，处理月底、闰年和夏令时；日历展示实例但编辑原计划。
3. [浏览器完成；真机待验收] 提醒投递：权限状态、页内提醒、Service Worker 通知请求、跨标签去重、完成/取消后不再提醒。
4. [完成] 关怀服务端：每位成员一条当前信号，允许需要类型、可选短消息、1—72 小时过期；发布、查询、撤回与 RLS。
5. [完成] 关怀界面：发布前预览，只发送需要和短消息，不发送私人草稿/周期；对方可见到期时间，作者可撤回。
6. [自动化完成] Memory/PostgreSQL、双账号浏览器、重复/时区边界、通知允许/拒绝/去重和回归。

## 完成定义

浏览器内提醒、重复与双账号关怀通过可标记本地完成；真实 iPhone/安卓后台精确定时需真机和操作系统权限验收，单独保留边界。
