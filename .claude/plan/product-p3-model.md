# P3 真实青鸟助手实施计划

## 目标

在不把密钥暴露给浏览器的前提下，为青鸟接入可配置模型服务；模型只接收用户明确允许的资料片段，输出可验证结构，保留来源引用。本地检索永远可独立使用。

## 子任务

1. [完成] 服务端模型配置与状态接口：端点、模型名、密钥、超时、最大资料条数；浏览器只看到能力状态。
2. [完成] 回答请求：浏览器先本地检索并展示待发送范围，再由服务端调用模型；资料 ID 与正文长度受限，私人/待确认资料在客户端和服务端双重拒绝。
3. [完成] Structured Outputs：固定 `answer`、`citationIds`、`uncertainty`，服务端再次校验 ID 与结构；拒绝/无效 JSON/超时回退到本地检索。
4. [完成] 流式与取消：服务端 SSE，浏览器中止后终止上游请求；重复点击不产生并行旧回答。
5. [完成] 设置与日志：模型启用、资料范围、运行状态、服务商错误；不记录密钥和完整私人正文。
6. [测试提供商完成；真实端点待配置] 验收：测试提供商覆盖成功、结构错误、虚假引用、拒绝、超时、断流、取消和无配置。实际模型端点完成一次问答与候选整理后，才将 P3 标记完成。

## 官方依据

- OpenAI Responses API 使用 `text.format` 提供严格 JSON Schema。
- 流式响应使用 SSE；浏览器取消由服务端 AbortController 传递给上游。

## 完成定义

代码和测试提供商通过记为“实现完成、实际端点待验收”；只有真实可用端点成功且资料范围核对无误，才能记为 P3 完成。
