# P4 完整导入与识别实施计划

## 目标

在保留来源、逐条确认和隐私边界的前提下，支持聊天文本、TXT、JSON、CSV、HTML、图片 OCR 与录音转写；导入过程可刷新恢复。微信只接受用户主动取得并选择的文件或粘贴文字，不尝试读取个人微信数据库。

## 子任务与状态

1. [完成] 本地文件解析：TXT、JSON、CSV、HTML；限制文件大小、消息条数与字符数，错误不覆盖当前内容。
2. [完成] 可恢复批次：原始整理文本、映射、范围、日期和步骤存入账号 IndexedDB；图片/音频二进制不持久化，刷新后提示重新选择。
3. [测试提供商完成] OCR：登录后由服务端向配置的 vision 模型发送图片；浏览器明确同意、显示文件名/大小，结果必须人工校正。
4. [测试提供商完成] 录音转写：服务端 multipart 转发到 `/audio/transcriptions`；格式/大小限制、取消、错误恢复和来源标签。
5. [完成] 来源：OCR/转写/CSV/HTML 保留文件名、整理文本行号和识别方式；候选仍需确认。
6. [完成] 本地解析、刷新恢复、测试 OCR/转写提供商、取消/非法格式/超限/敏感候选和回归。
7. [外部依赖] 实际图片与音频识别质量，需真实端点与模型配置后验收；微信直连能力需另行核实官方许可。

## 完成定义

本地格式与恢复流程通过可标记完成；OCR/音频代码和测试提供商通过只记为“实现完成”。实际图片/录音在真实端点完成识别、人工校正与来源追溯后，P4 才能最终通过。
