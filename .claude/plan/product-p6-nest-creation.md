# P6 鹊巢与创作深化实施计划

## 目标

让小鹊成长来自可查看的共同回忆来源；在不改变角色身份的前提下增加动作反馈；创作可在逐次确认资料范围后调用模型；时光胶囊正文由服务端加密并按时间控制读取。

## 子任务

- [x] 成长来源：服务端从已确认共享回忆生成幂等成长操作，记录来源 ID、标题和贡献值；撤回/删除来源后不再展示该来源。
- [x] 鹊巢动作：在四个批准姿态上增加梳羽、送信、探索等动作动画和事件，不伪造新的角色图。
- [x] 创作助手：信件/日常/年度回顾选择已确认非私密来源，发送前预览；结构化生成草稿，只填编辑器，不自动保存。
- [x] 服务端胶囊：独立表、AES-256-GCM、作者/共享范围、开启时间；未到期响应不含密文或正文，禁止前端提前预览。
- [x] 胶囊界面：登录共同空间后封存服务端胶囊，列表只显示封面元数据；到期后读取正文；作者可删除。
- [x] 验收：Memory/PostgreSQL、双账号、时间边界、密文、导出、模型失败/取消、成长来源与旧功能回归。

## 完成定义

成长来源和服务端胶囊通过本地/数据库验收；创作模型代码与测试提供商通过。实际模型辅助写作仍依赖 P3 的真实端点验收。
